# Lucas Falk — Personal Portfolio

Welcome to my personal portfolio! This project was developed to introduce myself, showcase my technical skills, share my learning journey, and provide contact information.

## About the Project

This portfolio is a personal website created as part of my Computer Science studies. It represents my current knowledge and development as a student and aspiring software developer.

## Pages

- **Home:** A brief introduction and overview of my profile.
- **About Me:** Information about my academic background, interests, and goals.
- **Attributes:** An overview of my technical and interpersonal skills.
- **Courses & Learning:** Completed courses, certificates, current studies, and learning resources.
- **Get in Touch:** Contact information and professional links.

## Technologies

- HTML5
- CSS3
- JavaScript

## Features

- Multi-page website.
- Responsive layout.
- Interactive navigation menu.
- Automatic footer year update.
- Technical skills section with technology icons.
- Course and certificate showcase.
- External links to professional profiles and learning resources.
